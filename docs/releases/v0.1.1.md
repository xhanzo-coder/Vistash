# Vistash v0.1.1 — 公开预览

Vistash 是 Windows 优先、本地优先的图片素材与提示词工作台。`v0.1.1` 聚焦图片—提示词关联管理和 Windows 桌面工作流，适合希望长期整理视觉参考、复用提示词并保留本地数据控制权的创作者。

> ⚠️ **未签名公开预览**：当前 NSIS 与 MSI 均未进行 Authenticode 签名，Windows 可能显示 SmartScreen 警告。请从本 Release 下载并核对 `SHA256SUMS.txt`；正式签名分发将在后续发布流程中单独完成。

## 本版本重点

- 图片页面可以选择已有提示词，也可以直接创建并关联提示词。
- 一条提示词可以关联多张图片；提示词页面使用“主预览 + 缩略图列表 + 打开当前图片”展示完整关系。
- 图片页和提示词页都提供独立的“解除关联”入口；解除关系不会删除任意一方素材。
- 图片、提示词、文件夹、标签、收藏和回收站继续保持本地可检索与可恢复。
- Windows 文件/文件夹拖放、文件列表粘贴、截图位图粘贴、原生对话框、默认程序打开、自定义标题栏、贴靠和窄窗口已完成真实桌面验收。

## 数据边界

- 导入会把图片复制进本地库，源文件不会被移动、删除或改写。
- 不需要账号，不上传素材，不提供云同步或网页抓取。
- 卸载程序不会删除 `%APPDATA%\com.vistash.app` 或用户选择的素材库。
- 当前版本不启用 Tauri updater，也不包含任何模型 provider/API Key 配置。

## 当前不支持

`v0.1.1` 不提供图像反推提示词、图像生成、恢复历史原始提示词、团队协作、云同步、浏览器采集或自动更新。Vistash 的长期产品目标是生成能在指定生图模型上重建相似视觉语言的控制提示词，但这不是本版本能力。

完整安装说明、开发命令、备份建议和边界说明见根目录 [`README.md`](../../README.md)。
