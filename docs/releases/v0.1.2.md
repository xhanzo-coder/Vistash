# Vistash v0.1.2 — 公开预览

Vistash 是 Windows 优先、本地优先的图片素材与提示词工作台。`v0.1.2` 改进首次运行体验、图片文件夹组织和检查器操作，并保持现有素材库格式兼容。

> ⚠️ **未签名公开预览**：当前 NSIS 与 MSI 均未进行 Authenticode 签名，Windows 可能显示 SmartScreen 警告。请只从本 Release 下载，并核对 `SHA256SUMS.txt`；正式签名分发将在后续发布流程中单独完成。

## 本版本重点

- 重新设计首次运行欢迎页，明确说明本地库、源文件和磁盘占用边界，并分开“创建新库”与“打开已有库”。
- 新增匿名欢迎页展示图片，深色与浅色主题均使用同一套本地资产，不进行网络加载。
- 文件夹树支持折叠、展开和同级排序；顶栏新建文件夹始终建立在库根，右键菜单可以新建子文件夹。
- 图片卡片右键菜单补充重命名与复制图像，检查器预览图也可打开相同的上下文操作。
- 修复图片导航收起按钮遮挡“全部图片”入口的问题，并保留宽栏、窄栏和抽屉布局。

## 下载与校验

| 文件 | 用途 |
| --- | --- |
| `Vistash_0.1.2_x64-setup.exe` | NSIS 安装器，适合普通安装 |
| `Vistash_0.1.2_x64_en-US.msi` | Windows Installer，适合管理部署 |
| `SHA256SUMS.txt` | 两个安装器的 SHA-256 权威清单 |

PowerShell 校验示例：

```powershell
Get-FileHash .\Vistash_0.1.2_x64-setup.exe -Algorithm SHA256
Get-FileHash .\Vistash_0.1.2_x64_en-US.msi -Algorithm SHA256
```

请把输出与同一 Release 中的 `SHA256SUMS.txt` 逐项比较；若不一致，请不要安装。

## 升级与数据

- `v0.1.2` 不改变素材库格式，现有 `v0.1.1` 库可以直接打开。
- 安装升级不会删除 `%APPDATA%\com.vistash.app` 或使用者选择的素材库。
- 导入继续采用复制入库，库外源文件不会被移动、删除或改写。
- 应用不需要账号，不上传素材，不提供云同步、网页抓取或自动更新。

## 当前不支持

`v0.1.2` 不提供图像反推提示词、图像生成、恢复历史原始提示词、团队协作、云同步、浏览器采集或自动更新。Vistash 的长期产品目标是生成能在指定生图模型上重建相似视觉语言的控制提示词，但这不是本版本能力。

完整安装说明、开发命令、备份建议和边界说明见根目录 [README.md](https://github.com/xhanzo-coder/Vistash/blob/main/README.md)。
