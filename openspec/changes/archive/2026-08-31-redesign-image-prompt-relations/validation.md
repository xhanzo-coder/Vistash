# 图片—提示词普通关联验收

日期：2026-08-31。

## 已验证行为

- 新 `image-prompt-relations` 深 Module 通过唯一公共出口提供判别联合命令、按库写入—刷新队列、逐提示词部分失败与正常区/回收站定位；query key 不暴露，第四个模块已纳入结构边界检查。
- 匿名公共工作区回归复现并修复“提示词侧写入成功、图片详情因 `staleTime: Infinity` 仍显示旧关联”：`execute` 等待图片详情、候选、提示词快照和活动关联分区全部刷新后才返回；切库刷新严格隔离。
- 权威写入成功而读取失败时返回独立 `refreshError`，界面保留提交选择并明确说明“关系已写入、刷新失败”；永久删除缺失错误不发过期导航，先刷新两侧关系。
- 图片侧关联提示词显示标题/正文摘要/模型/删除态，主体打开提示词，解除进入次级菜单；搜索多选 Dialog 显示已关联状态和关系数量。
- 提示词侧关联图片 DTO 由 Rust 返回显示文件名、文件夹、尺寸和删除态；对象格位主体打开图片，封面/解除进入菜单；搜索多选 Dialog 保留已关联候选并禁用重复提交。
- 从本地导入并关联、已入库但未关联、显式/缺省封面和永久删除回落的原有测试继续通过。

## 验证证据

- 前端完整门禁：48 个 Vitest 文件、421 项测试及 17 项 Node 合同测试通过。
- Rust：Clippy `-D warnings`、304 项核心测试与全部集成/文档测试通过；`linked_image_states_report_trash_state_in_order` 锁定 DTO 和回收站顺序。
- 匿名浏览器：深浅主题 × 1440/960/760 六组无水平溢出、无页面错误；关联对象、Dialog、键盘菜单与焦点由组件/公共工作区回归覆盖。
- release WebView2 每次从固定基线复制独立运行库，已完整通过提示词文件夹、两图关联、显式封面、双向打开、删除态关联定位、备注和收藏落盘；结束后清理运行副本，脚本不保存用户真实素材截图。

## 尚需用户确认

完整双向视觉体验仍需在用户真实 App 中确认；Windows Shell 文件/剪贴板/贴靠等桌面动作属于图片工作区 11.5 的同一最终人工门禁。

## 2026-08-31 最终复审

同库 `execute`/`synchronize` 已按库串行；本地导入并关联、两侧删除/还原/purge 均进入同一刷新屏障。永久删除携带 removed IDs，图片详情不再重读不存在对象；任意提示词删除态变化都会刷新图片详情。release E2E 额外断言图片 purge 后提示词权威与检查器均无旧哈希、提示词 purge 后图片检查器无旧提示词。Standards 与 Spec 双轴终审均给出实现轴 `MERGE`，三个 change strict validate 通过。
