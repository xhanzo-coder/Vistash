## REMOVED Requirements

### Requirement: 提示词记录仅追加不覆盖

**Reason**：第一版产品决策将提示词建模为一条可直接编辑的当前素材，不向使用者暴露版本、编辑派生记录或 append-only 历史。

**Migration**：当前运行时尚未持久化任何提示词记录，因此无旧记录转换；新实现以稳定 Prompt ID 保存当前值。若后续需要版本历史，必须通过新 OpenSpec 变更引入。

### Requirement: 提示词来源区分与溯源

**Reason**：本变更只实现图片与提示词管理，图片反推、编辑派生谱系、provider 与生成来源均延后；强制来源类别会迫使使用者对普通提示词和关联图片做无法验证的声明。

**Migration**：当前无持久化数据需要丢弃来源字段。后续反推变更可为它自身产出的提示词增加可验证的来源记录，但不改写现有普通关联。

## MODIFIED Requirements

### Requirement: 提示词库的检索与复用

提示词库 MUST（必须）支持卡片瀑布流和文本详情列表浏览，并支持按标题或正文文本、零个或多个共享标签、一个提示词文件夹位置、收藏状态与正常/回收站位置组合查询。多标签 MUST（必须）使用 AND 语义；标题缺省时，列表与搜索结果 MUST（必须）使用正文首行作为可识别标题。

使用者 MUST（必须）能把提示词正文写入系统剪贴板。收藏 MUST（必须）作用于稳定的提示词素材，MUST NOT（禁止）建模为星级、旗标、颜色评级或不可见版本的状态。

#### Scenario: 按正文与两个标签检索

- **WHEN** 使用者输入正文关键词 `cinematic` 并选择 `人物` 与 `逆光`
- **THEN** 结果只返回正文匹配且同时具有两个标签的正常提示词素材

#### Scenario: 无标题提示词使用正文首行

- **WHEN** 一条提示词未填写标题
- **THEN** 中央视图和全局搜索用正文首行标识该素材，不要求先补标题

#### Scenario: 复用一条提示词

- **WHEN** 使用者对活动提示词执行复制
- **THEN** 该素材当前的唯一正文被写入系统剪贴板

## ADDED Requirements

### Requirement: 提示词素材当前值与显式保存

提示词素材 MUST（必须）具有稳定唯一标识与一份去除首尾空白后非空的当前正文。标题、模型/平台和参数说明 MAY（可以）缺省，但 MUST NOT（禁止）存在第二份主提示词、负向提示词或隐藏版本。

正文、标题、模型/平台与参数说明 MUST（必须）在明确编辑状态中修改，并由“保存”或 `Ctrl+S` 显式更新当前值。存在未保存修改时，切换素材、折叠编辑器、切换库或关闭窗口 MUST（必须）提供保存、放弃或留在当前页的选择。保存失败 MUST NOT（禁止）丢弃编辑草稿或退出编辑状态。

#### Scenario: 编辑并覆盖当前提示词

- **WHEN** 使用者修改正文并执行保存
- **THEN** 同一 Prompt ID 的当前正文被原子更新，列表只显示更新后内容且不创建历史版本

#### Scenario: 带未保存修改切换素材

- **WHEN** 使用者在正文存在未保存修改时选择另一条提示词
- **THEN** 界面要求选择保存、放弃或留在当前提示词，不静默覆盖草稿

### Requirement: 提示词文件夹、共享标签与独立根位置

提示词文件夹 MUST（必须）使用与图片文件夹相同的合法名称、层级路径、多文件夹成员关系、根位置与批量回滚语义，但 MUST（必须）使用与图片彼此独立的文件夹树。同路径字面值 MAY（可以）在两个文件夹树各自存在，不表示混合文件夹。

提示词 MUST（必须）使用与图片共享的标签规范与词表，但提示词标签使用数量、筛选与回收站排除 MUST（必须）仅在提示词库中计算。

#### Scenario: 两库存在同名文件夹

- **WHEN** 图片文件夹树与提示词文件夹树各自创建路径 `人物/室内`
- **THEN** 两个路径独立存在且只组织各自类型的素材

#### Scenario: 提示词移回根位置

- **WHEN** 使用者移除一条提示词的最后一个提示词文件夹成员关系
- **THEN** 提示词仍正常存在并出现在提示词根位置，不出现同名持久化节点

### Requirement: 提示词卡片瀑布流、详情列表与检查器

提示词卡片瀑布流 MUST（必须）以提示词素材而非关联图片作为卡片身份。有关联图片时，卡片 MUST（必须）最多展示一张可选封面与剩余图片数量；无图片时 MUST（必须）展示可识别的纯文本卡片，MUST NOT（禁止）要求上传占位图。

详情列表 MUST（必须）以标题/正文摘要、提示词文件夹、共享标签、关联图片数、模型/平台、收藏与更新时间为主要列。右检查器 MUST（必须）呈现完整当前正文、组织、备注与全部关联图片；长文本编辑 MAY（可以）进入可扩展聚焦编辑器，但 MUST（必须）保持返回原列表位置的能力。

#### Scenario: 无图片提示词出现在卡片瀑布流

- **WHEN** 一条提示词没有任何关联图片
- **THEN** 它以纯文本卡片正常出现，正文可读且不显示虚假生成结果

#### Scenario: 有多张图片的提示词只展示一张封面

- **WHEN** 一条提示词关联五张图片且一张被设为封面
- **THEN** 卡片展示该封面和 `+4` 计数，完整五张图片只在检查器中展开

### Requirement: 提示词备注与收藏

每个提示词素材 MUST（必须）持久化一份多行纯文本备注与一个二值收藏状态。备注 MUST NOT（禁止）解析 Markdown 或富文本，并 MUST（必须）在停止输入后与失焦时自动保存，显示保存中、已保存或失败状态。保存失败 MUST NOT（禁止）丢弃草稿。

收藏 MUST（必须）只表示收藏/未收藏，并可在左侧固定入口和批量操作中筛选或更改，MUST NOT（禁止）扩展为星级或其他评分体系。

#### Scenario: 提示词备注自动保存

- **WHEN** 使用者修改备注并停止输入
- **THEN** 备注自动写入当前提示词素材，检查器呈现明确保存状态

#### Scenario: 筛选收藏提示词

- **WHEN** 使用者进入提示词库收藏入口
- **THEN** 中央视图只返回收藏状态为真的正常提示词素材

### Requirement: 提示词多选与批量组织

提示词卡片瀑布流与详情列表 MUST（必须）共用活动项与多项选择模型，支持 `Ctrl+单击`、`Shift+单击`、`Ctrl+A` 和卡片框选。多选时 MUST（必须）显示选中数量、批量工具条以及共同/混合组织值。

批量操作 MUST（必须）至少包含加入/移出提示词文件夹、添加/移除共享标签、收藏/取消收藏、建立普通图片关联与移入提示词回收站。提示词正文与备注 MUST NOT（禁止）提供批量覆盖。

#### Scenario: 批量把提示词加入文件夹

- **WHEN** 使用者选择二十条提示词并加入文件夹 `人像/室内`
- **THEN** 全部目标提示词保留其他文件夹成员关系并新增该成员关系，失败项逐条显示错误码

### Requirement: 提示词库内回收站与还原

删除提示词 MUST（必须）把其权威文件移入提示词库内回收站，记录删除时间与删除前提示词文件夹，MUST NOT（禁止）删除任何关联图片。还原 MUST（必须）恢复仍存在的原文件夹；原文件夹缺失时 MUST（必须）显式列出缺失路径并在必要时返回提示词根位置。

清空提示词回收站 MUST（必须）显示将永久删除的数量并二次确认，取消 MUST NOT（禁止）执行写入。永久删除后普通图片关联 MUST（必须）从权威元数据与派生索引移除，图片素材 MUST NOT（禁止）被修改或删除。

#### Scenario: 删除关联图片的提示词

- **WHEN** 使用者把关联三张图片的提示词移入提示词回收站
- **THEN** 提示词不出现在正常查询中，三张图片本体和图片元数据均保持不变

#### Scenario: 还原原文件夹已缺失的提示词

- **WHEN** 还原提示词时部分删除前文件夹不再存在
- **THEN** 提示词恢复到仍存在的文件夹，界面列出缺失路径且不静默改写历史归属

#### Scenario: 永久删除提示词不删图片

- **WHEN** 使用者确认永久清空包含一条关联图片的提示词
- **THEN** 提示词与其普通关联永久消失，关联图片仍可在图片库正常浏览
