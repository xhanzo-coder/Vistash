# 图片会话切片验收（8.2）

日期：2026-08-27。本轮承接已存在的 8.1 失败行为测试，实现 8.2；保留此前 UI 基础修复的未提交改动。

## 实现与真实契约

- `asset-library/index.ts` 导出真实 `AssetLibraryWorkspace`。查询、偏好、定位去重、选择与 query key 均位于模块 `internal/`，不向外壳传递刷新版本。
- 校正 8.1 测试中的传输假设：`catalog_snapshot` 查询 Rust 当前库，不接收 `libraryId`；缓存 key 和布局读写携带库身份。测试在同一 QueryClient 中切换后端当前库，避免每次新建客户端掩盖串库问题。
- 恢复六个已消费的查询/视图字段，保留其他已有布局字段；只有后端明确返回 null 才建立首次默认状态。读取失败不查询集合，不覆盖旧偏好；写入失败保留草稿、错误与手动重试入口。
- 以同库 mutation scope 串行保存，落盘前读最新根对象，只覆盖图片分区，保留提示词分区。缓存中的失败草稿在同进程重开后仍显示错误，不冒充已落盘。
- 定位请求按 requestId 去重；当前集合内定位不重新查询，目标不在当前条件下时清除限制并切换正确的活动库/回收站位置。非活动工作区不加载数据或认领定位。
- 收藏作为本阶段最小权威 mutation：仅失效本库集合与目标详情，不刷新其他库；视图切换不触发集合查询。
- 集合切片使用真实 TanStack Virtual lanes，缩略图通过现有平台租约读取；项卸载及异步返回后已卸载时释放租约。未使用前端像素处理、旧 AssetWorkspace 包装或 prototype 实现。

## 已运行的失败回归

1. 8.1 原有六项测试最初因公开出口没有组件实现而失败；保留原有六个业务验收目标，修正库身份 mock、共享客户端及不安全类型断言后实现转绿。
2. 1,000 条记录的 DOM 检查先得到 1,000 个选项，窗口化后通过少于 40 个选项的检查。
3. 收藏失效测试先因缺少收藏入口失败；实现后只有当前库新增集合查询。
4. 保存失败后的同库重开测试先发现错误提示丢失；改为观察 QueryClient 中对应 mutation 的结果后，草稿与错误一起保留。

其余公开 interface 回归覆盖非活动状态、读失败及手动重试、保存时保留另一工作区最新偏好、按库串行写入。
