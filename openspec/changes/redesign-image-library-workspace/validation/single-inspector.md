# 单选检查器验收（9.3）

日期：2026-08-28。任务 9.3 完成，当前进度 60/75。承接现有未提交开发成果，不切换默认 App，不提交、推送或归档。

## 实现范围

- 摘要、色卡、组织、备注、关联提示词、文件信息六个连续纵向分区，独立展开/折叠。定位按钮展开目标并把焦点交给其标题，不使用互斥 Tab。
- 分区状态按库写入图片布局，可选覆盖字典严格校验；保留最新集合滚动偏移和提示词布局。
- 摘要复用显式缩略图租约，不读取原图像素；色卡呈现 Rust 提供的 HEX、角色、比例或真实失败码。
- 组织支持移动到唯一文件夹或未分类、添加/移除标签、收藏切换。写入失败保留输入与错误码，同库组织 mutation 互斥。
- 备注为多行纯文本，800ms 停顿、失焦、Ctrl+Enter 或“保存备注”触发保存；保存中继续输入不会被旧结果覆盖，同图不会并发写入。失败草稿按库/哈希保留，切图或关闭覆盖检查器不丢失；切库取消尚未发出的定时写入，不在卸载后向新的当前库补写。草稿仅在当前应用进程内保留，不声称支持进程退出恢复。
- 关联读取使用私有详情 key，候选按需搜索正常提示词；一次明确选择一条提示词建立关联，也可解除正常提示词关联。已删除提示词仍显示标记并禁止编辑。这里只操作现有普通记录，不涉及图像反推。
- 文件信息保留既有重命名入口，新增媒体类型、字节数、导入时间、来源路径和内容哈希；来源路径缺失明确显示“未记录来源路径”，不伪造剪贴板来源。
- 回收站信息只读。窄窗口关闭检查器时不创建隐藏桌面副本，不读取隐藏详情；宽窄呈现共用备注协调器。

## 红—绿回归

全部行为测试通过 `asset-library/index.ts` 渲染，在 Tauri IPC 接缝模拟后端，不导入内部组件进行协作者 mock。图片模块从 42 项增加至 54 项。

新增覆盖：六分区折叠/定位/按库恢复；备注保存、失败切图保留与重试；在途保存与新输入；切库取消及同哈希草稿隔离；单选组织与失败输入；普通提示词建立/解除；回收站只读及详情失败重试；摘要/色卡；延迟焦点竞争；窄屏按需读取；关联候选查询失败；分区保存不覆盖滚动与提示词布局。

回归捕获并修复：

1. 集合的 `requestAnimationFrame` 延迟聚焦会抢走刚定位到检查器的焦点。冻结帧回调的公开 interface 测试先稳定复现，再限定旧选择请求的焦点所有权，分区无需延迟聚焦或强抢焦点。
2. 滚动偏移只更新缓存，其他布局控件使用旧本地状态时会覆盖最新偏移。先用分区折叠回归复现，再在布局提交时合并最新缓存，不以延时补写掩盖。
3. 既有跨库测试把“搜索框恢复”误当成“虚拟图片渲染完成”；现在分别等待两种可观察状态，不修改测试池、超时或运行门禁。
