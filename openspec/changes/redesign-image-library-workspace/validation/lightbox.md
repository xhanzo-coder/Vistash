## 实现范围

- 双击图片或按 Enter 进入单图灯箱，单击仍只更新检查器。打开时固定当前查询的有序轻量记录，上一张/下一张及左右键按该顺序浏览，首尾不循环。
- 关闭按钮或 Esc 返回集合，选中最后查看的图片，保留查询、排序、视图和打开前的滚动位置。最后图片在原视口外时聚焦集合容器，后续 Enter 仍能打开它，不为聚焦强制滚动。
- 支持适合窗口、100%、加减按钮、滚轮缩放、指针拖动和 Shift+方向键平移。缩放最大 800%，拖动限制在图片溢出的边界内；Home 恢复适合窗口，1 恢复 100%。
- 100% 按图片元数据的固有尺寸对应 CSS 像素呈现；Windows DPI 由 WebView 处理。适合窗口不放大小图。
- 深色、浅色和棋盘格媒体背景独立于应用主题，沿用 Archive Desk 语义 token 与紧凑工具栏。灯箱不调用原生全屏，不改变 Windows 标题栏。
- 原图通过现有 `acquireOriginal` 租约读取，图片以 img 和 CSS transform 呈现，无 Canvas 或前端像素处理。每次切图/重试都有独立请求身份，迟到结果立即释放，换源、关闭和切库释放已取得的租约。
- 原图读取失败保留后端错误码；浏览器显示失败使用明确的前端 `viewer.decode_failed`。均提供手动重试，错误时不显示缩略图替代原图。回收站也能查看原图；停用工作区、切库或新的外部定位关闭旧灯箱。

## TDD 与行为回归

测试通过 `asset-library/index.ts` 公开 interface 渲染，只在 Tauri IPC 边界模拟数据。新增 5 项行为测试，图片模块共 73 项：

1. 双击才读取原图，按排序切换，Esc 返回保持滚动与最后活动项。
2. 适合窗口、100%、有界拖动、键盘平移和背景切换。
3. 原图读取/显示错误与明确重试，不自动重试。
4. 迟到请求不覆盖当前图片，返回同一哈希也不复用已释放 URL，换源和关闭释放租约。
5. 停用工作区或切库关闭灯箱，回收站允许显式预览。

红—绿循环同时捕获 Portal 尚未挂载时测量画布的问题：现在通过实际节点建立尺寸观察，不依赖父组件的布局 effect 时序。集合聚焦增加明确的预览返回请求，防止虚拟列表自动滚到最后查看的远处图片。

## 浏览器与视觉验收

`app/scripts/lightbox-check.py` 使用 `webapp-testing` 的 Python Playwright 与 Windows headless Edge，覆盖深/浅主题、1440×900/760×600。测试使用本地 1024px 品牌原图、128px 缩略图和匹配的原图元数据，不打开真实素材库。

验证真实显示尺寸、滚轮缩放、拖动、键盘平移、背景选择、连续切到第 16 张后返回原位置、再次 Enter 打开最后图片、错误重试、弹层焦点保持、关闭时 URL 释放及无水平溢出。截图和报告保存在 `app/artifacts/lightbox/`，已查看深色宽屏适合窗口、浅色窄屏棋盘格和窄屏错误状态。
