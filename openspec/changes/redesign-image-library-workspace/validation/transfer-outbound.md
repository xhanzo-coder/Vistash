# 图片传输任务与出站能力验收（10.3–10.4）

日期：2026-08-29。图片入站、内部任务协调和出站操作已经接入新版图片模块与应用壳层。

## 实现范围

- 导入和导出统一注册 `appTaskCenter` 内部任务，使用同一个库级传输并发键；重复任务返回 `transfer.already_running`。
- 图片回收站的批量还原与清空也注册为不可停止的 `batch_organization` 内部任务，异常报告由回收站就地保留；切库或组件卸载不会把未执行项伪装成成功。
- 内部任务记录进度、当前文件、成功/跳过（非图片、重复内容或同名冲突）/失败/未处理计数、逐项显示名与稳定错误码。收到后端 task ID 后保存可停止状态，但当前界面不展示停止按钮；后端确认并收到结果后才把内部终态记为“已停止”。
- 应用壳层不展示任务中心；图片工作区只呈现与当前操作有关的就地异常报告，关闭报告不停止运行中的业务任务。
- 单选提供“复制图像”和“使用默认程序打开”；多选不合成图片，只提供“导出原图”。复制/打开的失败在按钮附近持续显示错误码，成功显示短暂状态。
- 导出先调用只读 `plan_export`，同名冲突提供跳过、自动编号和覆盖；覆盖必须经过二次确认，确认前不调用写入 command。导出结果进入同一任务报告。
