## 审查与改动

Hallmark 只读审查确认三个主要结构偏差：

- **严重：设计系统结构漂移**。生产 `AssetLibraryWorkspace.tsx` 将库名横跨三栏置顶，侧栏与检查器一起下移。现已将库名放入导航，将当前集合名和实际结果数放入中央标题，三栏从同一高度开始。
- **主要：控件层级相同**。`AssetNavigator.tsx` 将所有导航做成普通描边按钮，文件夹动作位于中央查询栏。现改为扁平图标行，文件夹增删改回到侧栏分区，并保留完整可访问名称；中窄窗口保留图标导航和完整导航 Dialog。
- **主要：图片优先的层级未落实**。`AssetCollection.tsx` 中档卡片基准宽度 280px，宽屏仅三列，文字条常驻。现三档为 160/200/280px，1440px 宽屏默认四列；名称和尺寸在悬停、键盘焦点、选中时增强呈现。

初始范围：1 项严重、2 项主要。修复后这三项按本批检查通过；工具栏重复入口、上下文动作堆积、检查器与列表信息列等**不属于已完成项**，仍按第 12 组任务推进。没有声称全页面通过 Hallmark 全部门禁。

预检沿用 `app/src/styles/tokens.css` 的 Bahnschrift / Microsoft YaHei UI、Georgia / SimSun、石墨/骨白双主题与暖珊瑚强调、4px 间距；使用 React、CSS Modules、Phosphor CSR 图标，不添加依赖、动效库或新的 token 系统。此处恢复已批准的桌面工作台，不套用网页 Hero、手机框架或主题轮换规则。

## 性能脚本纠正

旧 `measure-perf.mjs` 查找 `.asset-waterfall` / `.asset-detail-list`，生产 CSS Modules 已不再包含这些类；真实浏览器探针得到 `oldScroller=false`、`actualScroller=true`。旧脚本又回退到 `document.scrollingElement`，因此此前图片滚动数字不能证明真实集合滚动性能。

现用图片集合的真实语义定位，缺少滚动容器直接失败；每步检查滚动偏移确实增加。新结果单独写入纠偏目录，不覆盖历史 `perf-baseline.json`。

10,000 项 release 前端、1440×900、每次实际滚动 900px，共 45 次的串行复验：

| 场景 | 首屏 ms | 初始 / 峰值 DOM | 平均 / 最坏双帧 ms | heap MiB | 切换 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 图片瀑布流 | 117 | 18 / 28 | 12.86 / 16.4 | 48.59 | 35 |
| 图片详情列表 | 4 | 11 / 13 | 13.24 / 15 | 47.75 | 32 |
| 提示词卡片 | 5 | 14 / 28 | 13.7 / 13.9 | 48.54 | 23 |
| 提示词列表 | 4 | 18 / 25 | 13.7 / 14 | 47.82 | 29 |

首次与 Vitest 并行时提示词列表切换为 59ms，超过 50ms；随后停止并行并串行复验，未修改阈值。以上是 IPC fixture 的前端渲染指标，不包含 Rust 编目耗时或实机导入验收。

## 第二轮：操作显隐与图标语言

2026-08-29 用户实机截图指出中央查询栏、检查器顶部标签和单选底栏的信息冗余。第二轮不增加功能，以“频率 × 当前选择上下文”重排现有入口：

- 顶栏导入菜单新增剪贴板，成为非空库唯一常驻导入入口；空集合引导、Ctrl+V 和拖放继续存在。
- 中央查询栏收为一行，只保留搜索、排序、密度滑杆、瀑布流/列表图标和窄屏导航/信息图标；不再呈现导入或单图动作。
- 单选动作放入检查器摘要，以 Phosphor 的复制、外部打开、导出、编辑和收藏图标呈现，全部保留 `aria-label`；单选不显示底部批量栏。
- 多选底栏只直接呈现导出、移动、标签和一个收藏状态；关联提示词与移入回收站进入“更多批量操作”。右侧多选检查器只汇总共同/混合值，不复制动作。
- 删除检查器顶部六个重复定位标签；折叠分区标题继续承担导航。删除多选英文 eyebrow 和解释性废话。
- 左栏、单图与多图标签统一为轻量圆角 chip，标签名与计数分离；单图移除使用 `X` 图标，添加使用 `Plus` 图标。
- 色卡失败主文案改为“暂时无法生成色卡”，稳定错误码收进“技术详情”。

TDD 的公开 seam 为 `AppShell` 与 `asset-library/index.ts`：先观察到顶栏缺少剪贴板、查询栏重复导入、单选错误出现批量栏、检查器存在重复定位标签，再实施。新增/修订回归后，图片模块 86 项通过；完整前端门禁与浏览器矩阵见本轮最终检查。
