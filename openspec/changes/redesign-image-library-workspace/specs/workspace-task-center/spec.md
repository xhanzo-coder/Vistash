## ADDED Requirements

### Requirement: 长任务协调不占据应用顶栏

应用 MUST（必须）保留内部任务 ID、并发键、进度、停止确认和结果记录，用于协调导入、导出、库迁移、文件夹批量变更和素材批量组织；紧凑顶栏 MUST NOT（禁止）展示任务中心入口、运行数量或任务详情。切换图片和提示词工作区 MUST NOT（禁止）停止任务或丢失内部状态。

当前切片不提供全局任务浏览界面。领域错误 MUST（必须）由发起操作的就地区域、阻断对话框或短暂 Toast 呈现，MUST NOT（禁止）为了显示内部任务记录重新增加顶栏入口。

#### Scenario: 切换工作区时导入继续

- **WHEN** 图片导入进行中且使用者切换到提示词工作区
- **THEN** 导入继续运行且内部任务状态保持，顶栏不显示任务摘要

#### Scenario: 顶栏保持简洁

- **WHEN** 后台存在运行中的导出任务
- **THEN** 顶栏仍只显示搜索、导入和设置，不增加任务按钮

### Requirement: 任务并发键与真实停止状态

内部任务协调 MUST（必须）以明确的任务 ID 标识每个任务，并 MUST（必须）使用库级并发键阻止同一库的重叠导入。可停止任务 MUST（必须）区分运行中、正在停止、已停止、成功、部分成功与失败状态；只有后端确认停止后才能记录已停止。当前界面不提供全局停止入口，这些状态用于保证并发、后端协议与发起区域结果一致。

迁移在使用者解决冲突且尚未提交时 MAY（可以）退出；一旦进入权威写入阶段 MUST NOT（禁止）提供会产生半迁移状态的取消。普通批量组织在本变更中 MUST NOT（禁止）冒充可取消任务。

#### Scenario: 阻止重叠导入

- **WHEN** 同一库已有导入任务运行并再次请求导入
- **THEN** 内部协调拒绝启动重叠任务，发起区域显示当前已有导入正在运行

#### Scenario: 停止状态等待后端确认

- **WHEN** 使用者点击停止且后端仍在完成当前素材事务
- **THEN** 内部状态保持“正在停止”而不是提前记录“已停止”

#### Scenario: 迁移提交后不显示取消

- **WHEN** 使用者确认迁移且事务写入已经开始
- **THEN** 迁移页面显示不可取消的就地进度，并由成功或整体回滚结束

### Requirement: 完成报告与逐项失败

内部任务记录 MUST（必须）保留完整完成事实。导入与导出报告 MUST（必须）区分成功、重复或跳过、失败、停止和尚未处理；批量操作的失败 MUST（必须）逐项包含目标显示名与稳定错误码，MUST NOT（禁止）只记录失败总数。

成功且无需进一步处理的任务 MAY（可以）只保留内部终态；包含失败、部分成功或停止结果的任务 MUST（必须）在发起区域持续可见，切换工作区或素材库后返回仍保留，直到使用者明确关闭对应报告。

#### Scenario: 导入部分失败

- **WHEN** 一批导入中大部分成功且两张图片失败
- **THEN** 图片工作区就地报告同时显示成功数量、两张失败图片的显示名和各自错误码

#### Scenario: 已停止任务保留报告

- **WHEN** 使用者停止导出且部分文件已经完成
- **THEN** 导出发起区域保留已导出、失败和尚未处理的数量，直到使用者关闭报告

### Requirement: 就地错误、轻量通知与阻断反馈分层

字段编辑失败 MUST（必须）在对应控件附近呈现并保留未保存输入；短暂且无需处理的成功 MAY（可以）使用轻量通知；重要失败和长任务结果 MUST（必须）进入稳定的就地状态，MUST NOT（禁止）只使用会自动消失的通知。永久删除、覆盖文件和迁移提交等高风险操作 MUST（必须）使用阻断式确认。

浏览器 `alert`、只写“操作失败”的通用文案和没有错误码的失败提示 MUST NOT（禁止）作为生产反馈。

#### Scenario: 备注保存失败

- **WHEN** 图片备注自动保存失败
- **THEN** 备注区保留编辑文本并在该区域显示错误码，不只弹出短暂通知

#### Scenario: 复制图像成功

- **WHEN** 图片已经成功写入剪贴板
- **THEN** 应用可使用轻量通知告知完成，而不打开任务详情

#### Scenario: 永久覆盖导出文件

- **WHEN** 使用者选择覆盖已有导出文件
- **THEN** 应用在写入前显示明确的阻断式确认
