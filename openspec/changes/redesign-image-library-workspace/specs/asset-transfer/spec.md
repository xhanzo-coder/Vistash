## ADDED Requirements

### Requirement: 统一的图片导入入口

应用 MUST（必须）允许使用者通过文件选择、目录选择、整窗口拖放和工作区粘贴导入图片，并 MUST（必须）让这些入口复用相同的格式校验、内容哈希去重、复制入库、缩略图、索引、进度与错误语义。导入 MUST（必须）保留源文件和源目录不变，MUST NOT（禁止）移动、删除或改写库外内容。

顶栏导入操作 MUST（必须）明确区分“导入图片”和“导入文件夹”。导入期间窗口 MUST（必须）保持可浏览和可导航；同一库同一时间 MUST（必须）只运行一个导入任务。

#### Scenario: 从文件选择器导入多张图片

- **WHEN** 使用者选择多个受支持图片文件并执行导入
- **THEN** 文件进入与拖放相同的复制、去重、缩略图与索引流程，源文件保持不变

#### Scenario: 导入期间再次提交导入

- **WHEN** 当前库已有一个导入任务运行且使用者再次拖入图片
- **THEN** 应用不启动第二个重叠导入，并保持当前任务进度与结果归属

### Requirement: 文件夹导入保留相对层级并合并同路径

导入文件夹 MUST（必须）递归扫描受支持图片，并 MUST（必须）以所选目录名称为逻辑根保留其相对目录层级。导入到一个当前逻辑文件夹时，该逻辑文件夹 MUST（必须）作为所选目录逻辑根的父级。源目录中的非图片文件 MUST（必须）被跳过并计入结果，MUST NOT（禁止）作为失败阻断整批导入。

若规范化后的目标逻辑路径已经存在，系统 MUST（必须）合并到现有路径，MUST NOT（禁止）自动创建带编号副本或拒绝整批导入。内容重复的既有素材 MUST（必须）保持原文件夹归属，MUST NOT（禁止）因重复导入被静默移动。

#### Scenario: 导入嵌套目录

- **WHEN** 使用者导入包含 `灵感参考/人物/正面/01.png` 的目录树
- **THEN** 新素材唯一归属于逻辑文件夹 `灵感参考/人物/正面`

#### Scenario: 合并同路径目录

- **WHEN** 库中已有 `灵感参考/人物` 且导入目录产生相同逻辑路径
- **THEN** 新素材进入现有路径，不创建 `人物 (2)`

#### Scenario: 重复素材不被移动

- **WHEN** 导入目录包含一个已经存在于其他逻辑文件夹的同内容素材
- **THEN** 系统将其报告为重复且保持既有文件夹归属

### Requirement: 文件与位图剪贴板导入

图片工作区获得焦点且没有文本输入控件正在编辑时，`Ctrl+V` MUST（必须）尝试导入 Windows 剪贴板内容。剪贴板包含文件系统对象时，系统 MUST（必须）读取图片文件或目录路径并复用路径导入流程；剪贴板包含位图时，系统 MUST（必须）在 Rust 侧把位图编码为新的 PNG 素材。文件列表与位图同时存在时 MUST（必须）优先文件列表，MUST NOT（禁止）重复导入。

文本输入控件获得焦点时 `Ctrl+V` MUST（必须）保持普通文本粘贴。纯文本或网址 MUST NOT（禁止）触发网络下载或网页抓取。

#### Scenario: 粘贴资源管理器复制的图片

- **WHEN** 使用者在 Windows 资源管理器复制多张图片并在图片工作区按 `Ctrl+V`
- **THEN** 应用按完整路径导入这些图片并呈现统一任务进度

#### Scenario: 粘贴截图位图

- **WHEN** 剪贴板包含截图位图且图片工作区接收 `Ctrl+V`
- **THEN** Rust 侧生成带时间名称的 PNG 素材，前端不读取或处理像素

#### Scenario: 在备注中粘贴文本

- **WHEN** 备注文本框获得焦点且使用者按 `Ctrl+V`
- **THEN** 文本进入备注，不启动图片导入

#### Scenario: 拒绝网址抓取

- **WHEN** 剪贴板只包含图片网址
- **THEN** 应用不下载该网址且不启动导入任务

### Requirement: 导入与导出可以在安全边界停止

运行中的导入和导出任务 MUST（必须）提供停止操作。目录扫描尚未开始写入时 MUST（必须）尽快停止；素材处理期间 MUST（必须）在单素材事务边界观察停止请求，使当前素材完整成功或完整回滚后停止后续项。前端仅停止等待或隐藏进度 MUST NOT（禁止）冒充任务已停止。

停止后的报告 MUST（必须）区分已成功、重复或跳过、失败和尚未处理数量。导入停止前已经成功的素材 MUST（必须）保留；重新导入相同来源时 MUST（必须）通过内容哈希识别既有素材。

#### Scenario: 停止一万张图片导入

- **WHEN** 使用者在第 3421 张图片处理期间停止一万张图片的导入
- **THEN** 当前图片完整成功或回滚，后续图片不再处理，已成功素材保留且报告包含未处理数量

#### Scenario: 前端关闭任务详情

- **WHEN** 使用者只关闭任务中心详情但没有提交停止命令
- **THEN** 后端任务继续运行，应用不得把它标记为已停止

### Requirement: 原图导出与同名冲突处理

应用 MUST（必须）允许单选或多选素材导出到使用者明确选择的目录，并 MUST（必须）使用显示文件名与真实扩展名复制原始字节，MUST NOT（禁止）修改库内本体或侧车。目标存在同名文件时，系统 MUST（必须）要求使用者明确选择跳过、覆盖或自动编号，MUST NOT（禁止）静默采取任一策略。

批量导出 MUST（必须）以单素材为失败隔离单元并逐项报告结果；覆盖现有文件属于破坏性操作，执行前 MUST（必须）明确确认。

#### Scenario: 导出多张原图

- **WHEN** 使用者选择多张不同格式图片并导出到空目录
- **THEN** 目标目录获得使用各自显示文件名和真实扩展名的原始字节副本

#### Scenario: 导出发生同名冲突

- **WHEN** 目标目录已经存在与待导出素材同名的文件
- **THEN** 应用要求选择跳过、覆盖或自动编号，并在选择前不写该目标

### Requirement: 复制图像与默认程序打开

应用 MUST（必须）允许把一张选中图片的位图写入 Windows 剪贴板，以便粘贴到支持图像的外部程序。多选时应用 MUST NOT（禁止）把多张图片合成为一张位图；多选出站 MUST（必须）使用批量导出。

应用 MUST（必须）允许使用 Windows 默认程序打开一张库内原图。外部打开 MUST（必须）保持库内内容哈希对象不可被绕过应用改写；本变更 MUST NOT（禁止）承诺监控或回写外部编辑。

#### Scenario: 复制单张图片到外部软件

- **WHEN** 使用者选中一张图片并执行“复制图像”
- **THEN** Windows 剪贴板包含可被图像软件粘贴的位图

#### Scenario: 多选时不合成位图

- **WHEN** 使用者选中多张图片
- **THEN** “复制图像”不作为批量合成操作，界面提供批量导出

#### Scenario: 使用默认程序打开

- **WHEN** 使用者对一张图片执行“使用默认程序打开”
- **THEN** Windows 使用默认关联程序打开该素材，Vistash 不承诺接收外部修改
