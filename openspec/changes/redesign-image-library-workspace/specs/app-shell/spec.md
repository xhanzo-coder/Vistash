## ADDED Requirements

### Requirement: 启动恢复与库生命周期界面

存在可用的上次库记录时，应用 MUST（必须）直接打开该库并恢复上次工作现场，MUST NOT（禁止）先显示首页、统计面板或额外确认页。首次运行时应用 MUST（必须）使用独立欢迎界面提供“创建新库”与“打开已有库”，并 MUST（必须）说明素材会复制进库、库会占用磁盘空间且源文件不会被修改。

上次库路径不可用时，界面 MUST（必须）显示原路径与稳定错误信息，并 MUST（必须）提供重新定位该库或打开其他库的入口，MUST NOT（禁止）以空工作区冒充成功打开。空库成功打开后 MUST（必须）直接进入图片工作区，并在中央区域提供导入、拖放和粘贴引导。

#### Scenario: 启动时恢复工作现场

- **WHEN** 使用者启动应用且上次使用的库仍可用
- **THEN** 应用直接进入上次使用的工作区，并恢复该工作区的布局与查询状态

#### Scenario: 首次运行创建本地库

- **WHEN** 使用者首次启动应用
- **THEN** 欢迎界面解释本地库语义并提供创建或打开库的操作，不显示素材统计首页

#### Scenario: 上次库路径失效

- **WHEN** 记录的库路径不存在或不可读
- **THEN** 界面显示该路径与错误码，并提供重新定位或打开其他库的操作

### Requirement: 自定义窗口标题栏与紧凑应用顶栏

Windows 版本 MUST（必须）关闭 Tauri 原生标题栏装饰，并 MUST（必须）把窗口拖动区、最小化、最大化/还原和关闭控件合并进现有紧凑应用顶栏。搜索框、菜单、库切换器与窗口按钮 MUST NOT（禁止）成为拖动区。自定义标题栏 MUST（必须）保留窗口拖动、双击最大化、边缘缩放和 Windows 贴靠能力，关闭 MUST（必须）继续经过未保存提示词草稿保护。

紧凑顶栏只容纳 Vistash 品牌标识、当前库切换器、图片/提示词一级入口、全局搜索、导入主操作、设置和窗口控制，MUST NOT（禁止）展示全局任务中心入口或让品牌头部占据大块垂直空间。

当前库名 MUST（必须）作为可见切换入口，完整磁盘路径 MUST（必须）收进切换浮层或设置的库信息，MUST NOT（禁止）长期占据顶栏。切换浮层 MUST（必须）同时提供“新建素材库”与“打开其他库”，并 MUST NOT（禁止）把它们与向当前库“导入图片”混为同一操作。图像反推、生图和 provider 配置在本变更中 MUST NOT（禁止）成为可操作顶栏入口。

#### Scenario: 使用自定义窗口控件

- **WHEN** 使用者拖动顶栏空白区、双击该区域或点击最小化/最大化/关闭
- **THEN** Tauri 执行对应的 Windows 窗口操作，交互控件本身不触发拖窗

#### Scenario: 从顶栏切换素材库

- **WHEN** 使用者点击当前库名
- **THEN** 浮层显示当前库完整路径，并提供新建素材库和打开其他库的操作

#### Scenario: 取消选择其他库

- **WHEN** 当前库已打开，使用者选择“打开其他库”后取消系统目录对话框
- **THEN** 应用继续显示原库与原工作现场，不跳到首次运行欢迎页

#### Scenario: 顶栏提供核心入口

- **WHEN** 图片工作区已经打开
- **THEN** 使用者可从紧凑顶栏进入全局搜索、导入与设置，顶栏不出现任务中心入口

### Requirement: 有限范围的设置界面

设置 MUST（必须）以可关闭后返回原工作现场的 Dialog 呈现，并 MUST（必须）只显示当前真实可用的外观、素材库、快捷键和关于信息。外观 MUST（必须）允许选择跟随系统、深色或浅色；素材库 MUST（必须）显示当前库名称、完整路径与格式版本，并提供新建素材库和打开其他库的入口。

设置 MUST NOT（禁止）显示尚未实现的 provider、API Key、图像反推、云同步、账号、自动更新或语言选项。

#### Scenario: 切换主题后返回工作区

- **WHEN** 使用者在设置中把主题从跟随系统改为深色并关闭设置
- **THEN** 当前工作区保持原查询、选择与滚动位置，并立即使用深色主题

#### Scenario: 未实现设置不冒充可用

- **WHEN** 使用者打开本变更实现的设置界面
- **THEN** 界面不显示 provider、反推或云同步配置项

### Requirement: UI 基础的稳定布局与完整键盘操作

迁移冲突界面 MUST（必须）在支持的窗口尺寸中保持首尾操作区可见，并允许中间列表滚动到任意冲突；全部冲突选择完成前 MUST NOT（禁止）提交迁移。搜索清除 MUST（必须）保留输入焦点且不改变相邻工具的位置。主题单选组 MUST（必须）提供原生等价的方向键与 Tab 行为。紧凑文字按钮 MUST（必须）遵守常规操作文字至少 12px 的冻结基线。

#### Scenario: 长迁移列表仍能完成选择

- **WHEN** 在 760×600 或 1440×900 窗口呈现 60 个归属冲突
- **THEN** 底部确认区保持在窗口内，中间列表可滚动至最后一项，全部选择后才允许提交

#### Scenario: 清空搜索后继续输入

- **WHEN** 使用者点击清除按钮、用键盘激活清除或在输入中按 Escape
- **THEN** 查询清空，焦点保持在输入框，工具条相邻控件不产生横向跳动

#### Scenario: 使用键盘切换主题

- **WHEN** 焦点进入主题组并按方向键、Tab 或 Shift+Tab
- **THEN** 方向键在三个主题间循环选择，Tab 和 Shift+Tab 进出该组，不逐个遍历三个普通按钮

#### Scenario: 紧凑按钮仍可清晰阅读

- **WHEN** 呈现 compact 文字按钮
- **THEN** 操作文字至少为 12px，保持紧凑高度且不改变元数据字号

## MODIFIED Requirements

### Requirement: 可调整三栏工作台与独立布局记忆

每个素材库 MUST（必须）使用“左侧分类—中央集合—右侧检查器”的稳定桌面工作台。左右两栏 MUST（必须）支持调整宽度与折叠，中央内容 MUST（必须）获得剩余空间。图片库与提示词库 MUST（必须）分别保存左/右栏宽度、折叠状态、中央视图、当前文件夹、筛选、排序与滚动位置；图片库还 MUST（必须）保存缩略图尺寸和检查器分区折叠状态。

单击一个项目 MUST（必须）只更新活动项与右侧检查器，MUST NOT（禁止）用整页详情替换中央集合。双击或 `Enter` MUST（必须）进入聚焦模式，`Esc` MUST（必须）返回原集合位置。应用重新启动并打开同一库时 MUST（必须）恢复上次使用的一级工作区与其工作现场，MUST NOT（禁止）先进入首页。

#### Scenario: 图片与提示词记住不同布局

- **WHEN** 使用者在图片库展开右检查器、在提示词库折叠右检查器后来回切换
- **THEN** 两个素材库各自恢复先前的栏位与中央视图状态

#### Scenario: 单击不丢失集合上下文

- **WHEN** 使用者在瀑布流中单击一个项目
- **THEN** 右侧检查器展示该项目，中央瀑布流保持原滚动位置与可见项

#### Scenario: 重新启动后恢复图片密度

- **WHEN** 使用者调整图片缩略图尺寸并重新启动应用
- **THEN** 同一库的图片工作区恢复该尺寸、查询与滚动位置

### Requirement: 窄窗口适配与语义主题

工作台 MUST（必须）在窗口变窄时优先保留中央内容：中等宽度下左栏 MUST（必须）可折叠为按需展开的导航，更窄时右检查器 MUST（必须）作为覆盖式抽屉，MUST NOT（禁止）依赖固定最小宽度造成水平滚动。

界面样式 MUST（必须）使用表达表面、文本、边界、强调、选中、焦点、成功、警告与危险状态的语义主题 token，MUST NOT（禁止）把具体颜色值散落在业务模块规则中。应用 MUST（必须）提供跟随 Windows 系统、深色和浅色三种主题选择；深浅主题 MUST（必须）共用组件结构、状态选择器与交互语义。主题 MUST（必须）满足键盘焦点可见性与文本、控件、选中状态的对比度要求。

Vistash MUST（必须）使用一套受控的品牌强调色、字体组合、圆角、阴影、动效和图标语言，MUST NOT（禁止）使用随机彩虹强调、通用发光渐变或多套图标系统。减少动态效果 MUST（必须）尊重系统偏好。

#### Scenario: 窄窗口不产生水平滚动

- **WHEN** 使用者把窗口缩小到无法容纳三栏常驻的宽度
- **THEN** 左分类与右检查器按规则折叠或覆盖，中央内容不出现水平滚动

#### Scenario: 跟随系统主题变化

- **WHEN** 主题设置为跟随系统且 Windows 从浅色切换为深色
- **THEN** 应用替换语义 token 的取值而不改变组件布局和工作现场

#### Scenario: 减少动态效果

- **WHEN** Windows 启用减少动态效果
- **THEN** 应用关闭非必要位移和缩放动画，同时保留即时状态反馈
