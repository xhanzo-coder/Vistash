## MODIFIED Requirements

### Requirement: 标签规范与素材标签变更

标签 MUST（必须）是去除首尾空白后非空且不含控制字符的文本，规范化后的标签按字面值区分大小写。标签词表 MUST（必须）完全由使用者在图片或提示词上输入的合法字面值构成，系统 MUST NOT（禁止）预置题材、风格、模型、用途或其他固定标签集。图片素材与提示词素材 MUST（必须）共用该用户自定义词表，但标签应用、使用数量与筛选 MUST（必须）按当前素材库分开计算，MUST NOT（禁止）因同名标签自动建立图片—提示词关联。

为图片添加已经存在的同值标签或移除不存在标签 MUST（必须）是幂等成功，MUST NOT（禁止）产生重复值或错误。系统 MUST（必须）能从正常图片索引列出标签及其图片使用数量；图片回收站项 MUST NOT（禁止）计入。标签变更 MUST（必须）写入图片侧车并可由索引重建完整恢复。

#### Scenario: 同一标签在两库分别计数

- **WHEN** 标签 `赛博朋克` 应用于二十张正常图片和七条正常提示词
- **THEN** 图片库显示计数二十，提示词库显示计数七，两侧使用同一标签字面值

#### Scenario: 空库不预置标签

- **WHEN** 使用者打开尚未给任何图片或提示词添加标签的新库
- **THEN** 共享标签词表为空，界面只提供自定义标签的输入入口

#### Scenario: 重复添加相同图片标签

- **WHEN** 图片已经具有 `人物参考`，使用者再次添加同值标签
- **THEN** 操作成功且图片侧车中仍只有一个 `人物参考`

#### Scenario: 拒绝非法标签

- **WHEN** 使用者提交空白标签或含控制字符的标签
- **THEN** 系统返回 `library.tag_invalid`，图片侧车与索引均不改变

## ADDED Requirements

### Requirement: 图片瀑布流、详情列表与固定检查器

图片库中央区 MUST（必须）提供保留原始画幅比例的瀑布流和以缩略图、文件名、图片文件夹、标签、尺寸、格式、导入时间与备注摘要为列的详情列表。两种视图 MUST（必须）共用同一查询、排序、选择集合与活动项，切换视图 MUST NOT（禁止）清空当前上下文。

右侧检查器 MUST（必须）在单击图片时展示活动项，并将图片信息/色卡、组织、备注和关联提示词分为可定位的检查器分区。完整原图聚焦查看 MUST（必须）由双击或 `Enter` 显式进入，MUST NOT（禁止）成为单击的默认结果。

#### Scenario: 瀑布流切换到详情列表

- **WHEN** 使用者在已选图片并应用文件夹与标签筛选时切换到详情列表
- **THEN** 列表保留原查询与选择，并以信息列呈现同一结果集

#### Scenario: 单击图片只更新检查器

- **WHEN** 使用者在瀑布流中单击一张图片
- **THEN** 图片成为活动项且右检查器更新，瀑布流不被详情页替换

### Requirement: 图片备注与收藏

每个图片素材 MUST（必须）持久化一份多行纯文本备注与一个二值收藏状态。备注 MUST NOT（禁止）解析 Markdown 或富文本；停止输入后与失焦时 MUST（必须）自动保存，并显式呈现保存中、已保存或失败状态。保存失败 MUST NOT（禁止）丢弃当前编辑文本。

收藏 MUST（必须）只表示收藏/未收藏，MUST NOT（禁止）扩展为星级、旗标或颜色评级。图片库 MUST（必须）提供收藏筛选，备注与收藏 MUST（必须）保存于权威图片元数据并能从索引重建。

#### Scenario: 备注保存失败保留编辑内容

- **WHEN** 使用者编辑图片备注后权威元数据写入失败
- **THEN** 检查器显示稳定错误码且编辑框仍保留尚未保存的全部文本

#### Scenario: 筛选收藏图片

- **WHEN** 使用者进入图片库收藏入口
- **THEN** 中央视图只返回收藏状态为真的正常图片

### Requirement: 图片多选与批量组织

图片瀑布流与详情列表 MUST（必须）使用同一选择模型，并区分唯一活动项与多项选择集合。`Ctrl+单击`、`Shift+单击`、`Ctrl+A` 与瀑布流框选 MUST（必须）分别支持增减项、连续范围、当前查询全选与空间框选。多选时 MUST（必须）呈现选中数量与批量工具条，右检查器 MUST（必须）只呈现共同值/混合值与批量操作。

批量操作 MUST（必须）至少覆盖加入/移出图片文件夹、添加/移除标签、收藏/取消收藏、建立普通提示词关联与移入图片回收站。任一批量权威写入失败 MUST（必须）返回逐项结果或按已批准事务语义回滚，MUST NOT（禁止）以部分成功冒充全部成功。

#### Scenario: 跨视图保留图片多选

- **WHEN** 使用者在瀑布流选中十张图片后切换到详情列表
- **THEN** 十张图片仍处于选中集合，活动项与批量工具条保持可识别

#### Scenario: 批量添加图片标签

- **WHEN** 使用者对十二张选中图片执行添加标签 `构图参考`
- **THEN** 全部目标图片权威元数据与索引可查询到该标签，失败项以文件名和错误码呈现

### Requirement: 大图片集合的真正界面虚拟化

图片瀑布流与详情列表 MUST（必须）只为视口及其已记录过扫缓冲区创建集合项 DOM，MUST NOT（禁止）为全部 10,000 条查询结果同时创建卡片后只延迟图片字节请求。虚拟化 MUST（必须）保留键盘导航、活动项、多选范围、不同画幅高度与查询切换后的滚动语义。

#### Scenario: 打开一万张图片的瀑布流

- **WHEN** 当前查询匹配 10,000 张图片且只有首屏若干卡片可见
- **THEN** 首次渲染的集合项 DOM 数量只与视口和过扫缓冲区相关，滚动期间窗口保持响应
