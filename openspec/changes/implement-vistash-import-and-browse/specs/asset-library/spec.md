## ADDED Requirements

### Requirement: 缩略图契约

缩略图 MUST（必须）由 Rust 侧生成，并 MUST（必须）存放在库目录内独立于素材本体目录的位置，MUST NOT（禁止）与素材本体及其元数据侧车同目录。原因是同目录侧车的设计意图是"拷走一个叶目录即得到完整素材"，而缩略图是可重算的派生数据；把它混入权威目录会使缩略图重建操作向权威树写入，一次写入失败将与素材本体的完整性问题纠缠在一起。

缩略图 MUST（必须）保持素材的原始宽高比，MUST NOT（禁止）裁剪为固定形状。原因是画幅是素材的关键属性，裁剪成方形会使使用者在网格中对画幅产生误判。尺寸小于目标尺寸的素材 MUST NOT（禁止）被放大。

缩略图编码格式 MUST（必须）支持透明通道，因为素材可以是带透明区域的 PNG，丢失透明会在网格中显示为不存在的实色背景。

缩略图缺失时，系统 MUST（必须）按需重新生成，MUST NOT（禁止）以占位图代替而不重建。缩略图生成失败 MUST（必须）在网格中显式呈现为失败并携带原因，MUST NOT（禁止）显示空白格位——空白与"素材本身是空白图像"无法区分。

缩略图 MUST NOT（禁止）参与索引重建的完整性判定：缩略图全部缺失 MUST（必须）触发重新生成，MUST NOT（禁止）被报告为库损坏。

#### Scenario: 导入一张素材后检查缩略图位置

- **WHEN** 某个素材导入完成并生成缩略图
- **THEN** 该缩略图不位于素材本体与元数据侧车所在的目录

#### Scenario: 为非方形素材生成缩略图

- **WHEN** 素材的宽高比不是一比一
- **THEN** 缩略图保持原始宽高比，不被裁剪为方形也不被填充留白

#### Scenario: 为尺寸小于目标值的素材生成缩略图

- **WHEN** 素材的长边小于缩略图目标长边
- **THEN** 缩略图保持素材原始尺寸，不被放大

#### Scenario: 为带透明区域的素材生成缩略图

- **WHEN** 素材是含透明区域的 PNG
- **THEN** 缩略图保留透明区域，不出现被填充的实色背景

#### Scenario: 删除全部缩略图后浏览网格

- **WHEN** 缩略图文件被全部删除后使用者打开素材网格
- **THEN** 缩略图被重新生成，库不被报告为损坏

#### Scenario: 某个素材的缩略图生成失败

- **WHEN** 某个素材因解码失败而无法生成缩略图
- **THEN** 网格中该素材显式呈现为缩略图生成失败并携带原因，而不是显示空白格位
