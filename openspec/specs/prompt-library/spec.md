## Requirements
### Requirement: 提示词库的检索与复用

提示词库 MUST（必须）支持卡片瀑布流和文本详情列表浏览，并支持按标题或正文文本、零个或多个共享标签、一个提示词文件夹位置、收藏状态与正常/回收站位置组合查询。多标签 MUST（必须）使用 AND 语义；标题缺省时，列表与搜索结果 MUST（必须）使用正文首行作为可识别标题。

使用者 MUST（必须）能把提示词正文写入系统剪贴板。收藏 MUST（必须）作用于稳定的提示词素材，MUST NOT（禁止）建模为星级、旗标、颜色评级或不可见版本的状态。

#### Scenario: 按正文与两个标签检索

- **WHEN** 使用者输入正文关键词 `cinematic` 并选择 `人物` 与 `逆光`
- **THEN** 结果只返回正文匹配且同时具有两个标签的正常提示词素材

#### Scenario: 无标题提示词使用正文首行

- **WHEN** 一条提示词未填写标题
- **THEN** 中央视图和全局搜索用正文首行标识该素材，不要求先补标题

#### Scenario: 复用一条提示词

- **WHEN** 使用者对活动提示词执行复制
- **THEN** 该素材当前的唯一正文被写入系统剪贴板

### Requirement: 提示词素材当前值与显式保存

提示词素材 MUST（必须）具有稳定唯一标识与一份去除首尾空白后非空的当前正文。标题、模型/平台和参数说明 MAY（可以）缺省，但 MUST NOT（禁止）存在第二份主提示词、负向提示词或隐藏版本。

正文、标题、模型/平台与参数说明 MUST（必须）在明确编辑状态中修改，并由“保存”或 `Ctrl+S` 显式更新当前值。存在未保存修改时，切换素材、折叠编辑器、切换库或关闭窗口 MUST（必须）提供保存、放弃或留在当前页的选择。保存失败 MUST NOT（禁止）丢弃编辑草稿或退出编辑状态。

#### Scenario: 编辑并覆盖当前提示词

- **WHEN** 使用者修改正文并执行保存
- **THEN** 同一 Prompt ID 的当前正文被原子更新，列表只显示更新后内容且不创建历史版本

#### Scenario: 带未保存修改切换素材

- **WHEN** 使用者在正文存在未保存修改时选择另一条提示词
- **THEN** 界面要求选择保存、放弃或留在当前提示词，不静默覆盖草稿

### Requirement: 提示词文件夹、共享标签与独立根位置

提示词文件夹 MUST（必须）使用与图片文件夹相同的合法名称、层级路径、多文件夹成员关系、根位置与批量回滚语义，但 MUST（必须）使用与图片彼此独立的文件夹树。同路径字面值 MAY（可以）在两个文件夹树各自存在，不表示混合文件夹。

提示词 MUST（必须）使用与图片共享的标签规范与词表，但提示词标签使用数量、筛选与回收站排除 MUST（必须）仅在提示词库中计算。

#### Scenario: 两库存在同名文件夹

- **WHEN** 图片文件夹树与提示词文件夹树各自创建路径 `人物/室内`
- **THEN** 两个路径独立存在且只组织各自类型的素材

#### Scenario: 提示词移回根位置

- **WHEN** 使用者移除一条提示词的最后一个提示词文件夹成员关系
- **THEN** 提示词仍正常存在并出现在提示词根位置，不出现同名持久化节点

### Requirement: 提示词卡片瀑布流、详情列表与检查器

提示词卡片瀑布流 MUST（必须）以提示词素材而非关联图片作为卡片身份。有关联图片时，卡片 MUST（必须）最多展示一张可选封面与剩余图片数量；无图片时 MUST（必须）展示可识别的纯文本卡片，MUST NOT（禁止）要求上传占位图或把图片视觉置于正文身份之上。卡片 MUST（必须）优先呈现可读标题/正文摘要、模型/平台、标签和必要状态；复制、收藏等附属动作 MUST（必须）在悬停、键盘焦点或选中上下文可达且不遮挡主文本。

详情列表 MUST（必须）以标题/正文摘要、提示词文件夹、共享标签、关联图片数、模型/平台、收藏与更新时间为主要列，并 MUST（必须）具有可读列标题。窗口变窄时 MAY（可以）按更新时间、标签、文件夹的顺序隐藏次要列，但标题/正文摘要与关联图片数 MUST（必须）保持可见；完整值 MUST（必须）可由可访问文本或 title 获得。

右检查器 MUST（必须）把摘要、当前正文、组织、备注和关联图片呈现为连续可折叠分区，不使用顶部重复分区标签或互斥 Tab。单选摘要 MUST（必须）集中当前提示词操作；长文本编辑 MAY（可以）进入可扩展聚焦编辑器，但 MUST（必须）保持返回原列表位置的能力。多选时检查器 MUST（必须）切换为共同值、混合值与只读摘要。

#### Scenario: 无图片提示词出现在卡片瀑布流

- **WHEN** 一条提示词没有任何关联图片
- **THEN** 它以正文主导的纯文本卡片正常出现，复制与收藏可达且不显示虚假生成结果

#### Scenario: 有多张图片的提示词只展示一张封面

- **WHEN** 一条提示词关联五张图片且一张被设为封面
- **THEN** 卡片展示该封面和 `+4` 计数，完整五张图片只在检查器关联分区中展开

#### Scenario: 在详情列表查看提示词信息

- **WHEN** 使用者从卡片视图切换到详情列表
- **THEN** 列表以信息列呈现同一查询与选择集合，并保持活动项和滚动现场

### Requirement: 提示词备注与收藏

每个提示词素材 MUST（必须）持久化一份多行纯文本备注与一个二值收藏状态。备注 MUST NOT（禁止）解析 Markdown 或富文本，并 MUST（必须）在停止输入后与失焦时自动保存，显示保存中、已保存或失败状态。保存失败 MUST NOT（禁止）丢弃草稿。

收藏 MUST（必须）只表示收藏/未收藏，并可在左侧固定入口和批量操作中筛选或更改，MUST NOT（禁止）扩展为星级或其他评分体系。

#### Scenario: 提示词备注自动保存

- **WHEN** 使用者修改备注并停止输入
- **THEN** 备注自动写入当前提示词素材，检查器呈现明确保存状态

#### Scenario: 筛选收藏提示词

- **WHEN** 使用者进入提示词库收藏入口
- **THEN** 中央视图只返回收藏状态为真的正常提示词素材

### Requirement: 提示词多选与批量组织

提示词卡片瀑布流与详情列表 MUST（必须）共用活动项与多项选择模型，支持 `Ctrl+单击`、`Shift+单击`、`Ctrl+A` 和卡片框选。只有选择至少两条提示词时 MUST（必须）显示选中数量和底部批量工具条；右检查器 MUST（必须）只呈现共同/混合组织值和只读摘要。

批量操作 MUST（必须）至少包含加入/移出提示词文件夹、添加/移除共享标签、收藏/取消收藏、建立普通图片关联与移入提示词回收站。高频的文件夹、标签和单一收藏状态 MUST（必须）直接可见；低频关联与移入回收站 MAY（可以）收进同一“更多”菜单，但 MUST（必须）保持键盘可达。提示词正文与备注 MUST NOT（禁止）提供批量覆盖。部分失败 MUST（必须）保留固定目标、编辑意图和逐项错误码。

#### Scenario: 批量把提示词加入文件夹

- **WHEN** 使用者选择二十条提示词并加入文件夹 `人像/室内`
- **THEN** 全部目标提示词保留其他文件夹成员关系并新增该成员关系，失败项逐条显示错误码

#### Scenario: 从多选切回单选

- **WHEN** 批量操作导致部分提示词退出当前查询并只剩一条可见选中项
- **THEN** 批量编辑会话继续处理其固定失败目标，关闭后底部批量栏消失并恢复单选检查器

### Requirement: 提示词库内回收站与还原

删除提示词 MUST（必须）把其权威文件移入提示词库内回收站，记录删除时间与删除前提示词文件夹，MUST NOT（禁止）删除任何关联图片。还原 MUST（必须）恢复仍存在的原文件夹；原文件夹缺失时 MUST（必须）显式列出缺失路径并在必要时返回提示词根位置。

清空提示词回收站 MUST（必须）显示将永久删除的数量并二次确认，取消 MUST NOT（禁止）执行写入。永久删除后普通图片关联 MUST（必须）从权威元数据与派生索引移除，图片素材 MUST NOT（禁止）被修改或删除。

#### Scenario: 删除关联图片的提示词

- **WHEN** 使用者把关联三张图片的提示词移入提示词回收站
- **THEN** 提示词不出现在正常查询中，三张图片本体和图片元数据均保持不变

#### Scenario: 还原原文件夹已缺失的提示词

- **WHEN** 还原提示词时部分删除前文件夹不再存在
- **THEN** 提示词恢复到仍存在的文件夹，界面列出缺失路径且不静默改写历史归属

#### Scenario: 永久删除提示词不删图片

- **WHEN** 使用者确认永久清空包含一条关联图片的提示词
- **THEN** 提示词与其普通关联永久消失，关联图片仍可在图片库正常浏览

### Requirement: 查询切换不得绕过正文草稿守卫

存在未保存主字段时，文本搜索、文件夹、标签、收藏、回收站以及已应用筛选条件移除 MUST（必须）先使用已有保存/放弃/留在当前页选择，再执行最初请求的查询意图。未确认前 MUST NOT（禁止）改变查询、卸载编辑器或丢弃草稿；保存失败必须保持原上下文与草稿。

文件夹重命名/删除、标签/收藏/归属及回收站写入也可能让编辑目标退出当前查询，因此 MUST（必须）在权威写入之前解决草稿，而不是等写入成功后的查询跳转才询问。

#### Scenario: 收藏筛选排除正在编辑的提示词
- **WHEN** 修改未收藏提示词正文并点击只看收藏
- **THEN** 编辑器与原查询保留并询问三选一；留在当前页不切换，放弃后执行收藏筛选

#### Scenario: 保存失败与成功继续查询
- **WHEN** 草稿守卫选择保存后接口先失败、重试后成功
- **THEN** 失败时草稿与原查询保持，成功后执行最初的查询意图

#### Scenario: 文件夹变更先保护草稿再写入
- **WHEN** 编辑当前文件夹的提示词正文后请求重命名或删除该文件夹
- **THEN** 未确认、取消或正文保存失败时不发出文件夹写入；放弃或保存成功后才执行一次原始操作

### Requirement: 提示词 Archive Desk 工作台

提示词库 MUST（必须）与图片库共享同一 Archive Desk 设计系统、原生标题栏下的紧凑顶栏、语义主题 token、字体、暖珊瑚强调和 Phosphor 图标语言。宽屏 MUST（必须）使用“左侧提示词导航—中央提示词集合—右侧提示词检查器”三栏 Workbench；提示词工作区 MUST NOT（禁止）继续使用独立的旧全局视觉体系、装饰性英文 eyebrow、大块虚线空状态或同权重文字按钮堆叠。

提示词库 MUST（必须）独立保存左右栏宽度与折叠状态。1050px 以下 MUST（必须）把左栏收为按需导航，780px 以下 MUST（必须）把右检查器作为覆盖层；响应式自动状态 MUST NOT（禁止）覆盖使用者保存的宽屏偏好，中央内容 MUST NOT（禁止）产生水平滚动。

#### Scenario: 在两个一级工作区之间切换

- **WHEN** 使用者从已经调整栏宽的图片库切换到提示词库
- **THEN** 提示词库使用同一视觉系统但恢复自己的栏宽、折叠、查询、视图与滚动现场，不继承图片库布局值

#### Scenario: 窄窗口浏览提示词

- **WHEN** 窗口缩窄到无法容纳三栏常驻
- **THEN** 分类和检查器通过图标入口按需覆盖，中央提示词集合不发生水平溢出

### Requirement: 提示词操作按上下文显隐

提示词中央查询栏 MUST（必须）只常驻搜索、排序、密度、卡片/详情视图和窄窗口栏位入口。复制正文、编辑、收藏、删除和关联图片 MUST（必须）只在单选上下文呈现；底部批量栏 MUST（必须）只在至少选择两条提示词时呈现。右侧多选检查器 MUST（必须）只呈现共同值、混合值和只读摘要，MUST NOT（禁止）复制底部批量动作。

熟悉的单项动作 MAY（可以）使用图标按钮，但 MUST（必须）具有 `aria-label`、Tooltip、键盘焦点、按下与禁用状态。领域动作 MUST（必须）使用短而明确的中文文案；同一动作 MUST NOT（禁止）同时出现在查询栏、检查器和批量栏。

#### Scenario: 单选一条提示词

- **WHEN** 使用者在卡片或详情列表中单选一条正常提示词
- **THEN** 右检查器摘要呈现复制、编辑、收藏与移入回收站入口，中央查询栏和底部不重复这些动作

#### Scenario: 多选提示词

- **WHEN** 使用者选择至少两条提示词
- **THEN** 底部出现批量栏，右检查器只显示共同/混合值，正文与备注不冒充可批量覆盖字段

### Requirement: 提示词浏览范围与文件夹树使用统一交互

提示词的“全部提示词、收藏、提示词根位置、具体文件夹、回收站”MUST（必须）是互斥浏览范围；进入任一范围 MUST（必须）原子清理上一范围的文件夹、收藏、搜索和标签条件，MUST NOT（禁止）同时高亮多个范围。搜索框、标签按下态和范围导航已经表达的状态 MUST NOT（禁止）在中央区重复渲染为“只看收藏”“文件夹：…”等条件胶囊。

提示词文件夹树的命名与移动交互 MUST（必须）和图片文件夹一致：新建 MUST（必须）在树内即时输入；节点右键 MUST（必须）提供新建子文件夹、重命名、移动和删除；嵌套节点 MUST（必须）可直接移到顶层；开始拖动文件夹后，树顶部 MUST（必须）出现可命中的“移到顶层”放置区并在命中时高亮；指针拖动和键盘可达的移动 Dialog MUST（必须）共用同一事务化文件夹子树移动语义。移动提示词文件夹 MUST（必须）同步重映射所有后代路径与受影响提示词归属，MUST（必须）保留每条提示词不在该子树中的其他归属。

#### Scenario: 从收藏切换到提示词根位置

- **WHEN** 使用者先进入收藏，再点击提示词根位置
- **THEN** 只有提示词根位置保持选中，查询不再限制收藏，中央区不显示“只看收藏”胶囊

#### Scenario: 拖动提示词文件夹子树

- **WHEN** 使用者把 `人物/室内` 拖到 `构图` 文件夹
- **THEN** 子树变为 `构图/室内`，后代与提示词中的对应成员关系一并更新，提示词的其他文件夹归属保持不变

#### Scenario: 把提示词子文件夹拖回顶层

- **WHEN** 使用者拖动 `人物/室内` 到文件夹树顶部出现的“移到顶层”放置区并松开
- **THEN** 放置区命中态清晰可见，系统以 `destinationParent=null` 把子树移动为顶层 `室内`

### Requirement: 使用者可以手动新建提示词

提示词工作区 MUST（必须）在集合标题区和真正的空状态提供同一个“新建提示词”主动作。创建界面 MUST（必须）以正文为唯一必填字段，并 MAY（可以）填写标题、模型/平台和参数；打开创建器时的具体文件夹 MUST（必须）冻结为本次创建的初始归属，其他浏览范围 MUST（必须）创建到提示词根位置。创建界面 MUST（必须）支持主按钮与 `Ctrl+S`，写入失败 MUST（必须）保留全部草稿和稳定错误信息。

保存成功后工作区 MUST（必须）清理会隐藏新提示词的搜索、标签、收藏和回收站条件，进入新提示词的实际位置并聚焦它。创建器存在非空草稿时，返回列表、切换提示词范围、切换一级工作区、切库与关闭窗口 MUST（必须）全部经同一个全局脏草稿守卫要求保存、放弃或留在当前页，不得静默丢弃；外部导航 MUST NOT（禁止）改变已经冻结的初始归属。

#### Scenario: 在具体文件夹中新建提示词

- **WHEN** 使用者位于 `人物/室内`，填写正文并保存
- **THEN** 新提示词以 `人物/室内` 为初始归属，保存后该文件夹范围显示并聚焦新提示词

#### Scenario: 在收藏范围中新建提示词

- **WHEN** 使用者位于收藏范围并新建一条未收藏提示词
- **THEN** 新提示词创建在提示词根位置，工作区退出收藏条件、进入提示词根位置并聚焦新条目

#### Scenario: 新建草稿阻止切库

- **WHEN** 新建提示词正文已有未保存内容且使用者尝试打开其他素材库
- **THEN** 全局脏草稿守卫要求保存、放弃或留在当前页，选择留在当前页时草稿和初始归属均保持不变
