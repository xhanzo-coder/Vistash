# PROTOTYPE — 双素材工作台

> **可丢弃原型，禁止复用其代码到生产 `src/`。**

本原型只回答：图片与提示词两个素材库的信息架构、四种中央视图、右侧检查器、多选、搜索和普通关联是否好用。它不连接 Tauri、真实库、SQLite 或文件系统。

原型里出现的文件夹和标签只是内存 fixture 的用户示例数据，不代表产品内置分类。正式产品的文件夹与标签全部由使用者自定义。

三个变体在单一路由上通过 `?variant=A|B|C` 切换：

- `A — 平衡工作台`：左/中/右三栏常驻。
- `B — 内容优先`：窄导航与覆盖检查器。
- `C — 编目台`：宽分类栏与强调信息的检查器。

底部的“虚拟化”按钮或查询参数 `engine=owned|tanstack` 用于比较小型自有定位器与 `@tanstack/react-virtual@3.14.10`。它只是选型实验，不代表两套实现都会进入生产。

运行：

```powershell
cd app
pnpm prototype:dual-assets
```

打开 `http://localhost:1421/?variant=A&engine=tanstack`。

原型内存中各生成 10,000 条图片和提示词数据，底部状态条会显示当前库、视图、查询数、活动项、选中数和实际 DOM 数。
